# 资源清理与验证

按本次代码涉及的资源选择检查，不要求无资源副作用的静态页面执行整套内存分析。

## 创建与销毁必须配对

| 资源 | 清理与边界 |
| --- | --- |
| `setTimeout` / `setInterval` | 保存标识并 clear；重启前清理旧任务。异步轮询避免前一次未完成就发起下一次，停止时也阻止完成回调重新调度 |
| `requestAnimationFrame` | 保存并取消最后的帧标识；停止后不再续订 |
| DOM/window/document 事件、事件总线 | 使用可移除的同一个回调解除注册；DOM 移除时匹配事件类型和 capture；不要在每次渲染或更新时重复注册 |
| store、路由、SDK 等订阅 | 保存返回的 unsubscribe、stop 或 dispose，并在所属作用域结束时调用；检查库是否已经绑定作用域，避免重复管理 |
| Resize/Intersection/MutationObserver | 对拥有的 observer 执行 disconnect；只移除单个共享观察目标时使用相应 unobserve，避免影响其他消费者 |
| WebSocket / EventSource | 关闭拥有的连接、移除监听并取消重连定时器；共享连接按订阅或引用关系释放，页面退出不能断开其他页面仍使用的连接 |
| Worker、图表、编辑器等实例 | 调用实际库提供的 terminate/destroy/dispose，移除附带事件；重新初始化前释放旧实例，不猜测销毁 API |
| 对象 URL、文件、Blob、预览和大型数据 | 对不再被使用的 `URL.createObjectURL` 结果调用 revokeObjectURL，清除不再需要的引用；替换预览与销毁时均检查，不在图片仍使用或下载未接管前过早释放 |
| Map、数组、缓存、DOM 引用 | 移除过期条目和失效 DOM 引用；全局缓存明确容量、淘汰或到期清除机制，单纯记录时间戳不等于释放内存 |

## Vue 生命周期注意事项

- 在 `setup` 中同步创建并归属组件的 watcher 通常由框架在卸载时停止；在异步回调中创建的 watcher 要明确绑定作用域或保存 stop，在退出时停止。
- `watch` / `watchEffect` 每轮产生的副作用，使用其清理回调处理失效，例如取消上一轮请求、释放上一轮资源。若使用特定版本新增的 API，先确认项目 Vue 版本支持。
- 手动创建的外部资源放在 `onUnmounted` 或所属 composable 的作用域清理中释放。不要把资源放进模块全局后让每个组件都重复创建或接管销毁。
- KeepAlive 的停用不等于卸载。仅活跃页面需要的轮询、动画和监听应在 `onDeactivated` 暂停，在 `onActivated` 按需恢复，并保证首次挂载和反复激活只启动一份。
- 弹窗关闭不一定卸载组件。若资源只应在弹窗打开时存在，跟随打开状态释放，而不是只等页面卸载。
- 非 Vue 项目使用目标框架的等价清理机制，不引入 Vue 依赖。

## 请求取消与竞态

- 使用当前请求客户端实际支持的取消机制；共享请求不由单个消费者擅自取消。取消和请求序号解决的是不同问题，需要时同时使用。
- 筛选、搜索、分页或路由参数快速变化时，让最新有效请求拥有状态更新权；在成功、失败和 finally 分支都防止旧请求修改当前状态。
- 任务停止或组件销毁后，不再写入失效视图、不触发后续重试或重新启动轮询。取消属于预期结束时不弹错误提示；真实异常沿用项目错误处理，不能静默吞掉。

## 验证方式

先检查每个创建点的所有者和所有退出路径，再验证受影响的运行行为：

- 反复进入退出页面、开关弹窗或激活停用缓存页，确认定时任务、监听、连接和实例数量不持续增加，退出后没有后台请求或重连。
- 快速切换筛选或分页，模拟旧请求后返回、接口失败和中途离开，确认数据与 loading 属于当前请求，且无重复提示或重复提交。
- 对预览、上传、图表或编辑器等资源密集功能，重复创建和销毁，观察残留 DOM、实例及引用；任务确实涉及内存问题时，在测试环境用浏览器 Memory 工具比较相同操作和回收后的堆快照，定位持续保留的对象。

一次堆大小波动或垃圾回收前的增长不能单独证明泄漏；构建、lint 和短时间使用也不能证明完全无泄漏。报告实际检查范围与证据，未做运行时验证时明确说明。
